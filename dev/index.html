ProximalSolvers.jl

ProximalSolvers provides coordinate descent and proximal methods for penalized estimation in Julia. We consider the problem

\[\min_x F(x) = f(x) + g(x),\]

where $f$ is a loss and $g$ is a penalty or a constraint. The package provides the optimization algorithms, while ProximalBase.jl provides the functions, their gradients and proximal operators, and the iterates.

Coordinate descent and proximal methods

Coordinate descent updates one coordinate or group at a time, using cached residuals or matrix products to avoid recomputing the loss after every step. Furthermore, passes over the active coordinates concentrate the work on a small set when the solution is sparse. Using the same engine, we compute penalty paths with screening, reweighted estimates, refits on a selected support, and the inner solves of proximal Newton.

Proximal gradient methods combine a gradient step on the loss with a proximal step on the penalty. In particular, we can use the nuclear norm for low-rank regression through its proximal operator, which thresholds the singular values. ADMM instead splits the problem into two proximal subproblems, one for each term in the objective.

Both approaches use solve!(x, f, g, solver), which updates the starting point x and returns a summary of the run. In particular, the choice of solver determines which structure of the loss and penalty the algorithm uses.
