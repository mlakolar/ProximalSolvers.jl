ProximalSolvers.jl

Learn least-squares lasso with coordinate descent (CD) and proximal gradient descent (PGD) in Julia, and the square-root lasso with CD. The ProximalBase.jl documentation covers the loss, penalty and iterate types; this package supplies algorithms to optimize them.

Is this package for me?

Use the current development version if you want to study lasso algorithms, control their updates, or experiment with ProximalBase. If you mainly want a ready-to-use statistical modeling workflow with regularization paths and cross-validation, also consider GLMNet.jl and Lasso.jl. We make no comparative speed or accuracy claim.

Current development version

This site describes GitHub master; the registered release can have different interfaces and features. Follow installation and check the support matrix for the problem and storage you need.

Your first solution

using ProximalBase, ProximalSolvers
X = [1.0 0.0; 0.0 2.0; 0.0 0.0]
y = [2.0, -2.0, 0.5]
f = (1 / length(y)) * LeastSquaresLoss(y, X)
penalty = NormL1(0.1)
beta = zeros(2)
result = solve!(beta, f, penalty, CDSolver(order=:cyclic, momentum=false))
@assert isapprox(beta, [1.7, -0.925]; atol=1e-7)
beta
2-element Vector{Float64}:
  1.7
 -0.925

LeastSquaresLoss means half the sum of squared residuals, not their mean. Multiplication by 1/n produces the conventional lasso objective. solve! modifies beta in place, and result.minimizer === beta.

The solvers optimize the same objective; they differ in how they update coefficients. These examples choose CDSolver(order=:cyclic, momentum=false) for reproducible output. For routine exploratory lasso work, CDSolver() is a reasonable starting point (random order and its default momentum behavior); set a seeded rng for repeatability. Always check optimality independently before reporting fitted coefficients. See Choosing a solver for the difference between the settings.

A larger L1 penalty can make coefficients exactly zero, as the next tutorial shows.

The Problems and Solver comparisons sections of the sidebar have runnable scripts. The introductory guide examples above and below also execute during the documentation CI build.

Package API

ProximalSolvers — Module
ProximalSolvers

Least-squares lasso, with or without weights (NormL1(λ) or NormL1(λ, w)), and elastic net (an unweighted ElasticNet) with dense Matrix designs, for CDSolver, ProximalGradientDescent and AccProxGradDescent. CDSolver also solves least-squares ridge with uncentered SqrNormL2. ProximalGradientDescent and AccProxGradDescent also solve the least-squares problem with a NormLinf penalty (the largest magnitude of the entries); CDSolver does not. CDSolver also solves the square-root lasso, with ProximalBase's SqrtLeastSquaresLoss and an unweighted NormL1, and reports converged = true for it only with a duality certificate. CDSolver accepts a dense Vector or a one-dimensional SparseIterate as the iterate, and, for a group lasso with a GroupNormL2 penalty, a BlockIterate. For a matrix response Y and a GroupNormL2 whose groups are the rows of the coefficients, it accepts a Matrix coefficient (or a BlockIterate over its entries) with a dense X, Y and LeastSquaresLoss. ProximalGradientDescent and AccProxGradDescent accept a dense Vector only, all through solve!; ProximalGradientDescent and AccProxGradDescent also solve the group lasso with a GroupNormL2 penalty on it. ProximalGradientDescent also supports IndNonnegative() and unweighted NormL1Nonneg on a feasible dense Vector. Losses, proximal operators and coordinate storage belong to PB.
