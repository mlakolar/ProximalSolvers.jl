ProximalSolvers.ProximalSolver — Type
ProximalSolver

Abstract supertype of CDSolver and ProximalGradientDescent, passed to solve!.

source
ProximalSolvers.CDSolver — Type
CDSolver(; maxpasses=100_000, tol=1e-7, order=:random, relative=true,
           momentum=nothing, rng=Random.default_rng(), anderson=0,
           gaptol=0, gapsafe=false)

Dense least-squares lasso coordinate descent. A full pass admits coordinates; active passes refine them until another full pass checks strict change stopping. Random LS uses historical momentum by default. Set momentum=false to disable it; cyclic order refuses explicit momentum. The borrowed RNG advances between solves. Anderson, gap certificates and screening are deferred and explicitly rejected.

ProximalSolvers.ProximalGradientDescent — Type
ProximalGradientDescent(; ls=LineSearches.BackTracking(), normalized=false,
                         debias=0, preconditioner=:none)

Historical scalar-step dense LS lasso PGD, retaining its LS image cache, fused PB proximal call, TFOCS backtracking and FASTA/x/objective OR stopping. Normalized IHT, debiasing, preconditioning and custom searches are deferred.

ProximalSolvers.solve! — Function
solve!(x, f, g, CDSolver())
solve!(x, f, g, ProximalGradientDescent(), options=ProximalOptions())

Overwrite dense Vector{T} x, T=Float32 or Float64, for same-type Matrix X/Vector y and unweighted finite nonnegative NormL1. Use (one(T)/T(n))*LeastSquaresLoss for normalized lasso; raw LS keeps its unnormalized meaning. One positive finite scalar LS wrapper is supported. Borrowed X/y must not alias mutable x or change during a solve. Results share x; copy it to retain earlier coefficients. Unsupported inputs/options fail before mutation. Convergence uses historical stopping tests, not a KKT certificate. Finite intermediate arithmetic is required. CD errors before scatter preserve input x; PGD step errors restore its last accepted x and rethrow, without a transaction guarantee for internal counters.

ProximalSolvers.ProximalOptions — Type
ProximalOptions(; maxiter=200, ftol=1e-6, xtol=1e-8, gradtol=1e-5,
  allow_f_increases=false, store_trace=false, show_trace=false,
  extended_trace=false, print_every=1, callback=nothing, time_limit=Inf,
  f_calls_limit=0, grad_calls_limit=0, prox_calls_limit=0, gaptol=0, gapevery=10)

PGD retains objective-change, iterate-change OR FASTA residual stopping. This convergence flag is not a KKT certificate. Callback/display cadence is print_every; stored traces contain each iteration. A callback sees the trace when storing, otherwise the current state. Extended metadata copies x and its gradient. Call/time limits are checked after complete iterations, so counts may exceed limits by one iteration; zero call limits mean unlimited. Native Float32/64 buffers retain their arithmetic; scalar diagnostics use Float64. Tolerances below working precision do not imply corresponding coefficient accuracy. Positive gaptol is deferred and refused. Positive gapevery stays inert at gaptol=0.

ProximalSolvers.CDResults — Type
CDResults

Result sharing the caller's vector as minimizer, with minimum, passes, converged, maxchange and tolerance. Compatibility fields kkt_checks=0 and gap=NaN are sentinels, never computed certificates.

ProximalSolvers.OptimizationState — Type
OptimizationState{T<:ProximalSolver}

One iteration of a trace: iteration, the objective fg_x = f(x) + g(x), the relative change dxx = ‖x - x'‖ / ‖x‖, the inverse step size L, and a metadata dictionary that holds the iterate and gradient when extended_trace = true.

ProximalSolvers.OptimizationResults — Type
OptimizationResults

Qualified PGD result. minimizer aliases x; minimum, iterations, convergence flags, residuals/tolerances, trace, call and backtracking counts retain their historical meanings. iterationconverged means an iteration limit, not success. backtracksteps includes accepted nonzero trials. gap is a NaN sentinel, never a computed certificate.

ProximalSolvers.LineSearches.BackTracking — Type
BackTracking(; α = 0.9, β = 0.5, Lexact = Inf)

The backtracking line search of TFOCS (private/tfocs_backtrack.m). Each iteration starts from L ← α L, where 1/L is the step size, and while the local Lipschitz estimate L̂ of the step exceeds L it retries with L ← min(Lexact, max(L̂, L / β)). L̂ comes from function values until they are too close to compare in floating point, and from gradients after that. An LS trial whose image or value overflows is never accepted: it gives no estimate, and the search retries with L ← L / β.

The object holds settings only and can be shared between solves; the bookkeeping lives in the solver state.
