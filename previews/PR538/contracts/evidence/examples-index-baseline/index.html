Examples

The scripts here are documentation pages and tests at the same time. The documentation build turns each registered script into a page (see docs/make.jl), and test/examples.jl runs every .jl script under this folder, subfolders included. The checks of a script are @assert statements, so a failed check stops the script with an error.

How the folder is organized

  • problems/ holds one canonical tutorial per optimization problem, named after the problem (lasso.jl, elastic_net.jl, ...). A tutorial can solve its problem with several solvers, in separate sections.
  • comparisons/ holds comparisons of solvers on a problem, named <problem>_solvers.jl.
  • Some tutorials in problems/ are statistical applications of a supported problem rather than new problems. The documentation lists them under "Statistical applications", and they add no row to the matrix of Supported problems.
  • A solver is not a problem. A weighted lasso, for example, is LeastSquaresLoss with a weighted NormL1(λ, w). CDSolver, ProximalGradientDescent and AccProxGradDescent support it (see Supported problems), and it is documented in problems/weighted_lasso.jl, not as a separate solver.

A new script is registered in docs/make.jl, which stops with an error when a .jl script under this folder is not registered or a registered script is missing. A change that adds or removes support for a combination of problem, solver, iterate and element type also changes the matrix of Supported problems.

comparisons/lasso_solvers.jl measures the time each solver needs to reach the same independently measured objective gap and KKT violation. Its checks concern accuracy, and none concerns time. Run as a script it prints the comparison table and does not load Plots; the plot and the downloadable notebook are produced by the documentation build, and the notebook needs Plots in its environment. Its times are illustrative, from one machine and one run, and are not benchmark evidence; see Benchmarks and performance. comparisons/group_lasso_solvers.jl does the same for the group lasso, with a table and no plot or notebook; its times are illustrative in the same sense.
