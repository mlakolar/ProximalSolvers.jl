Numerical behavior

This page explains what a successful solve does and does not promise. You can start using the package without understanding its internal algorithm code.

This page keeps its published links. The full material is now organized in Learn and Contracts.

What does converged mean?

See the current section. Scalar CD step and range rules, including ridge with uncentered SqrNormL2, are in CD-01 and CD-04.

The stationarity check of a stop

See the current section. For least squares with NormL1 or ElasticNet on a dense vector the check holds each coordinate to its own scale, and an exact fit can return converged = false at an accurate point; see STOP-21.
